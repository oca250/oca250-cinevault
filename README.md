## How to Run This Project Locally

### Prerequisites

Before running the project, make sure you have:

- Git installed
- A web browser (Chrome, or Edge)
- Visual Studio Code (recommended)
- A YouTube Data API v3 key

### Clone the Repository

```bash
git clone https://github.com/kriss-v1/CineVault.git
```

### Navigate to the Project Folder

```bash
cd cineVault
```

### Open the Project

Open the project in Visual Studio Code:

```bash
code .
```

### Configure the API Key

```javascript
const API_KEY = "it cannot be pushed to github";
```

### Run the Project

- Open `index.html` in your browser, **or**
- Use the VS Code **Live Server** extension:
- Right-click `index.html`
- Select **Open with Live Server**

### Verify Everything Works

- The homepage loads successfully.
- The search bar returns movie trailers.
- Movie cards are displayed.
- Clicking a movie opens the trailer modal.

End of week1 progress note: By end of Week 1, the team has a working site that loads real trending trailers in a dark-theme grid, with a functioning live search bar.
